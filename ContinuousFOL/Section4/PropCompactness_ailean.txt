**Lemma** (`exists_common_zero`). If continuous functions $f_j:[0,1]^I\to\mathbb R$ have a common zero in the cube on every finite subfamily, they have a common zero in the cube.

*Proof.* Suppose there is no common zero, so the zero sets $Z_j=f_j^{-1}(0)$, which are closed by continuity, have empty intersection with the cube. The cube $[0,1]^I$ is compact by Tychonoff's theorem. So already finitely many of them, say $Z_j$ for $j\in s$, have empty intersection with the cube. This contradicts the hypothesis that the finite subfamily indexed by $s$ has a common zero in the cube.

**Lemma.** For a Łukasiewicz or continuous formula, $v\mapsto v(\varphi)$ is continuous on $\mathbb R^I$.

*Proof.* Induction on $\varphi$. A variable gives a coordinate projection, which is continuous, and each connective composes continuous functions with one of the continuous maps $(x,y)\mapsto\max(x-y,0)$, $x\mapsto1-x$ and $x\mapsto x/2$.

**Theorem** (`satisfiable_of_finite`, compactness). A set of formulae is satisfiable if each finite subset is.

*Proof.* Consider the family of functions $v\mapsto v(\varphi)$, one for each $\varphi\in\Gamma$; they are continuous by the previous lemma. A finite subfamily corresponds to a finite set $\Gamma_0\subseteq\Gamma$, which is satisfiable by hypothesis, so the subfamily has a common zero in the cube. By `exists_common_zero` the whole family has a common zero $v\in[0,1]^I$, and then $v(\varphi)=0$ for every $\varphi\in\Gamma$, i.e. $v$ satisfies $\Gamma$.

**Theorem** (`satisfiable_of_consistent`). For any $I$, a consistent $\Gamma$ is satisfiable (Łukasiewicz and continuous versions).

*Proof.* If not, compactness gives a finite unsatisfiable $\Gamma_0\subseteq\Gamma$. Then $\Gamma_0\models\varphi$ vacuously for every $\varphi$, so by finite strong completeness $\Gamma_0\vdash\varphi$ and hence $\Gamma\vdash\varphi$ for every $\varphi$: $\Gamma$ is inconsistent.

**Theorem** (`consistent_of_satisfiable`). If there is at least one propositional variable $P$, a satisfiable $\Gamma$ is consistent.

*Proof.* Let $v$ satisfy $\Gamma$. The formula $\neg(P\dot-P)$ has value $1$ under $v$, so by soundness it is not provable from $\Gamma$.

**Theorem** (`consistent_iff_satisfiable`, Facts 4.2 and 4.3). If $I$ is nonempty, $\Gamma$ is consistent iff it is satisfiable.

*Proof.* Combine the two preceding theorems. The hypothesis that $I$ is nonempty is used only in the direction from satisfiable to consistent.

**Theorem** (`consistent_iff_satisfiable_fails_empty`). With no propositional variables the equivalence fails for $\Gamma=\emptyset$.

*Proof.* If $I$ is empty there is no formula at all. By induction on formulae, a formula would have to contain a variable, and there is none to choose. Consistency of a set asks for some formula that it does not prove, so $\emptyset$ is not consistent. On the other hand the empty assignment satisfies $\emptyset$, since there is nothing to check.

**Theorem** (`entails_iff_forall_provable_tsub_pow2Neg`, Fact 4.4). $\Gamma\models\varphi$ iff $\Gamma\vdash\varphi\dot-2^{-n}$ for all $n$, where the constant $2^{-n}$ is the dyadic formula built from $\varphi$.

*Proof.* ($\Leftarrow$) By soundness every model has $v(\varphi)\le2^{-n}$ for all $n$, hence $v(\varphi)=0$. ($\Rightarrow$) Fix $n$. The conditions "every premise is $0$" and "$2^{-n}\dot-\varphi=0$" (i.e. $\varphi\ge2^{-n}$) have no common zero, since a common zero would be a model of $\Gamma$ with $\varphi\ne0$. By the compactness lemma some finite subfamily already has no common zero; let $\Gamma_0$ be the premises occurring in it. Then $\Gamma_0\models\varphi\dot-2^{-n}$, finite strong completeness gives $\Gamma_0\vdash\varphi\dot-2^{-n}$, and monotonicity gives the claim for $\Gamma$.

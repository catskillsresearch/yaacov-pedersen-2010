**Theorems** (`compactness_metric_pre`, `compactness_metric_complete`, `compactness_metric`). If every finite subset of $\Gamma$ is satisfiable in a metric pre-structure (resp. completely satisfiable), so is $\Gamma$.

*Proof.* Pre-structure clause: suppose every finite $\Gamma_0\subseteq\Gamma$ has a model in a metric pre-structure, but $\Gamma$ has none. If $\Gamma$ were metrically consistent, Theorem 9.4 would give it a metric pre-structure model in universe $0$, and that model transfers to the given universe. So $\Gamma$ is metrically inconsistent and proves the formula $1$. A derivation uses only finitely many premises, so some finite $\Gamma_0\subseteq\Gamma$ proves $1$. But $\Gamma_0$ has a model, and by metric soundness $1$ would have value $0$ there, whereas its value is $1$. Complete-structure clause: by the metric completeness theorem with soundness, complete satisfiability is equivalent to metric consistency, and the same argument applies with metric soundness for complete structures. The combined statement packages the two clauses.

**Theorem** (`henkin_adjoin_consistent`). Let $\Gamma$ be consistent, $p<q$, and $c$ a constant occurring neither in $\Gamma$ nor in $\varphi$. Then $\Gamma\cup\{(\sup_x\varphi\dot-q)\wedge(p\dot-\varphi[c/x])\}$ is consistent.

*Proof.* Suppose not. Since a conjunction is below each conjunct, adding either conjunct alone is already inconsistent, so (by the previous module and its mirror) $\Gamma\vdash q\dot-\sup_x\varphi$ and $\Gamma\vdash\varphi[c/x]\dot-p$. Choose $y$ fresh. Lemma 8.4 turns the second into $\Gamma\vdash\sup_y(\varphi[y/x]\dot-p)$; (A7) and (A9) give $\Gamma\vdash\sup_y\varphi[y/x]\dot-p$; and renaming the bound variable (Lemma 8.3) gives $\Gamma\vdash\sup_x\varphi\dot-p$. With (A2), $\Gamma\vdash q\dot-p$, a dyadic constant of positive value, hence $\Gamma\vdash1$.

**Definition** (`HCode`, `henkinSig`). Codes are generated by: the function symbols of $\mathcal L$; a constant $\mathrm{henkin}(\ulcorner\varphi\urcorner,x,p,q)$ for every code of a formula; and codes of variables, applications, atomic formulae, connectives and quantifiers, which are used to code $\mathcal L^c$-formulae. $\mathcal L^c$ has the relation symbols of $\mathcal L$ and all codes as function symbols; codes of $\mathcal L$-symbols keep their arities and moduli, every other code is a constant. The inclusion $\mathcal L\to\mathcal L^c$ is a signature extension. Formulae of $\mathcal L^c$ are coded injectively.

**Definition.** For $\tau=(\varphi,x,p,q)$ with $\varphi$ an $\mathcal L^c$-formula, $c_\tau$ is the Henkin constant of its code, $\psi_\tau=(\sup_x\varphi\dot-q)\wedge(p\dot-\varphi[c_\tau/x])$, and $\Gamma^c=\{\psi_\tau:p<q\}$.

**Size of codes.** Every code has a natural size, its number of constructors, counted with the sizes of its arguments. Two facts about size do the work that the paper's levels $\mathcal L_0\subseteq\mathcal L_1\subseteq\cdots$ do.

- If a symbol $c$ occurs in an $\mathcal L^c$-formula $\varphi$, then $\mathrm{size}(c)<\mathrm{size}(\ulcorner\varphi\urcorner)$. This holds because the code of $\varphi$ is built from the codes of its symbols by further constructors. It is proved by induction on terms and formulae.
- $\mathrm{size}(\ulcorner\varphi\urcorner)<\mathrm{size}(c_\tau)$ for $\tau=(\varphi,x,p,q)$, because $c_\tau=\mathrm{henkin}(\ulcorner\varphi\urcorner,x,p,q)$ has $\ulcorner\varphi\urcorner$ as an argument.

Consequently the Henkin constant $c_\tau$ never occurs in $\varphi_\tau$.

**Lemma** (`consistent_finite`, finitely many Henkin axioms). Let $\Gamma\subseteq\mathrm{For}(\mathcal L)$ be consistent and let $T$ be a finite set of indices $\tau=(\varphi,x,p,q)$, each with $p<q$. Then $e[\Gamma]\cup\{\psi_\tau:\tau\in T\}$ is consistent.

*Proof.* By strong induction on the finite set $T$. For $T=\emptyset$ this is `consistent_map` below. Otherwise choose $\tau\in T$ whose Henkin constant $c_\tau$ has maximal size among the Henkin constants of $T$, and put $T'=T\setminus\{\tau\}$. By the induction hypothesis $\Sigma=e[\Gamma]\cup\{\psi_{\tau'}:\tau'\in T'\}$ is consistent. To add $\psi_\tau$ by `henkin_adjoin_consistent`, we check that $c_\tau$ occurs neither in $\varphi_\tau$ nor in $\Sigma$.

- It does not occur in $\varphi_\tau$, by the size facts above.
- It does not occur in $e[\Gamma]$, because the image of an $\mathcal L$-formula uses only codes of $\mathcal L$-symbols, and a Henkin code is never such a code.
- Suppose it occurs in $\psi_{\tau'}$ with $\tau'\in T'$. The symbols of $\psi_{\tau'}$ are those of $\varphi_{\tau'}$, the dyadic constants (which contain no function symbols) and $c_{\tau'}$. If $c_\tau$ occurred in $\varphi_{\tau'}$, then $\mathrm{size}(c_\tau)<\mathrm{size}(\ulcorner\varphi_{\tau'}\urcorner)<\mathrm{size}(c_{\tau'})\le\mathrm{size}(c_\tau)$, which is impossible. If $c_\tau=c_{\tau'}$, then $\tau=\tau'$ because Henkin constants are coded injectively, contradicting $\tau'\in T'$.

Hence $\Sigma\cup\{\psi_\tau\}$ is consistent.

**Lemma** (`consistent_map`). If $\Gamma$ is consistent, so is $e[\Gamma]$ in $\mathcal L^c$.

*Proof.* Translate $\mathcal L^c$-formulae back to $\mathcal L$ by replacing every new constant with a variable $z$; axioms go to axioms for all $z$ outside a finite set, so a proof of $1$ from $e[\Gamma]$ would give a proof of $1$ from $\Gamma$.

**Theorem** (`exists_henkin_extension`, Proposition 9.2). (i) $e[\Gamma]\cup\Gamma^c$ is Henkin complete for every $\Gamma$; (ii) it is consistent whenever $\Gamma$ is.

*Proof.* (i) holds by construction. (ii) If $e[\Gamma]\cup\Gamma^c$ proved $1$, the proof would use only finitely many premises, hence only finitely many Henkin axioms $\psi_\tau$, $\tau\in T$. Then $e[\Gamma]\cup\{\psi_\tau:\tau\in T\}$ would prove $1$, contradicting `consistent_finite`.

**Theorem** (`exists_henkin_extension_metric`). The same with a metric: $\mathcal L^c$ keeps the metric symbol, and every metric axiom of $\mathcal L^c$ is provable from the images of the metric axioms of $\mathcal L$ (their instances only involve variables, dyadics and single symbols), so (ii) follows from the plain case applied to $\Gamma$ together with the metric axioms.

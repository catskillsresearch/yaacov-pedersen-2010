**Theorem** (`pavelka_completeness_pre`, Corollary 9.8). $\varphi^\circ_\Gamma=\varphi^\circledcirc_\Gamma$.

*Proof.* If $\Gamma$ is inconsistent, it proves $\varphi\dot-p$ for every dyadic $p$, so $\varphi^\circledcirc_\Gamma=0$; and it has no models, so $\varphi^\circ_\Gamma=\sup\emptyset=0$ (the real-number convention). Assume $\Gamma$ is consistent. ($\le$) If $\Gamma\vdash\varphi\dot-p$ then by soundness $\varphi\le p$ in every model, so $\varphi^\circ_\Gamma\le p$. ($\ge$) Let $p<\varphi^\circledcirc_\Gamma$ be dyadic. Then $\Gamma\nvdash\varphi\dot-p$, so by the refutation lemma $\Gamma\cup\{p\dot-\varphi\}$ is consistent; by completeness it has a model, in which $\varphi\ge p$. Hence $\varphi^\circ_\Gamma\ge p$, and since dyadics are dense, $\varphi^\circ_\Gamma\ge\varphi^\circledcirc_\Gamma$. The result is proved in universe $0$ and transferred to every universe; the metric version is identical.

Fix a metric signature with a recursive presentation $P$: an injective numbering $\varphi\mapsto\ulcorner\varphi\urcorner$ of formulae such that the set of codes is decidable, the operation $(\ulcorner\psi\urcorner,\ulcorner\varphi\urcorner)\mapsto\ulcorner\psi\dot-\varphi\urcorner$ is computable, and the codes of logical axioms (generalized instances of (A1)–(A14)) form an r.e. set.

**Definition** (proof sequences). A formula $\psi$ is *justified* by a finite list $\ell$ of formulae if $\psi\in\Gamma$, or $\psi$ is a logical axiom, or there is a $\varphi$ with both $\varphi$ and $\psi\dot-\varphi$ in $\ell$ (modus ponens). A list $\psi_0,\dots,\psi_{n-1}$ is a *proof from $\Gamma$* if each $\psi_i$ is justified by the strictly earlier entries $\psi_0,\dots,\psi_{i-1}$.

**Lemma** (`provableMetricQ_iff_exists_proof`). $\Gamma\vdash_Q\varphi$ if and only if some nonempty proof from $\Gamma$ ends with $\varphi$.

*Proof.* ($\Rightarrow$) By induction on the derivation of $\varphi$. An axiom or a hypothesis is a one-entry proof. If $\varphi$ comes by modus ponens from $\psi$ and $\varphi\dot-\psi$, which by induction have proofs $\sigma$ and $\tau$, then $\sigma\tau\varphi$ is a proof: the entries of $\sigma$ and of $\tau$ are still justified in the concatenation, because justification only looks at earlier entries and adding entries in front never removes them, and the final $\varphi$ is justified because the last entries of $\sigma$ and $\tau$ are $\psi$ and $\varphi\dot-\psi$. ($\Leftarrow$) By strong induction on $i$, every entry $\psi_i$ of a proof is derivable: a hypothesis or an axiom is derivable outright, and in the modus ponens case both premises are earlier entries, hence derivable by the induction hypothesis. Apply this to the last entry.

**Definition** (code proofs). The same notions are transferred to lists of natural numbers. A number $c$ is justified by a list $\ell$ of numbers if $c$ is the code of a member of $\Gamma$, or the code of a logical axiom, or there are $d,e\in\ell$ with $e$ the code of $c\dot-d$ (computed from $c$ and $d$ by $P$). A list of numbers is a *code proof* if every entry is the code of some formula and is justified by the strictly earlier entries.

**Lemma** (`provableMetricQ_iff_exists_code_proof`). $\Gamma\vdash_Q\varphi$ if and only if some nonempty code proof ends with $\ulcorner\varphi\urcorner$.

*Proof.* Because the numbering is injective, coding a proof entrywise gives a code proof, and decoding a code proof (every entry is a genuine code) gives a proof. Justification corresponds exactly under this translation, since the code of $\psi\dot-\varphi$ is determined by the codes of $\psi$ and $\varphi$. Combine with the previous lemma.

**Theorem** (`provableMetricQ_codes_re`). If the set of codes of members of $\Gamma$ is r.e., then the set of codes of formulae $\varphi$ with $\Gamma\vdash_Q\varphi$ is r.e.

*Proof.* We show step by step that the relevant predicates are r.e.

1. "Some $d,e\in\ell$ satisfy $e=\ulcorner c\dot-d\urcorner$" is decidable in $(\ell,c)$: it is a bounded search over the pairs of entries of the finite list $\ell$, testing equality with a computable function.
2. Hence "$c$ is justified by $\ell$" is r.e.: it is a disjunction of two r.e. conditions (membership in the codes of $\Gamma$, and in the codes of logical axioms) and the decidable condition of step 1.
3. "$\sigma$ is a code proof" is r.e.: "every entry is a genuine code" is decidable, and "for every $i<\mathrm{length}(\sigma)$ the $i$-th entry is justified by the first $i$ entries" is a bounded universal quantifier over an r.e. predicate composed with computable list operations, which is again r.e.
4. "$\sigma$ is nonempty and its last entry is $n$" is decidable.

By the previous lemma, $n$ is the code of a provable formula exactly when there exists a list $\sigma$ satisfying 3 and 4: if $\sigma$ ends with $n$, then $n$ is a genuine code $\ulcorner\varphi\urcorner$ and $\Gamma\vdash_Q\varphi$. An existential projection of an r.e. relation is r.e., which proves the theorem.
